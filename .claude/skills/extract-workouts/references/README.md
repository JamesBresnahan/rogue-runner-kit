# Known email formats

Each file in this directory documents one distinct source/layout of training
plan email, so `SKILL.md` can stay generic and this directory can grow as
more example emails are seen.

Name each file for its source, e.g. `trainingpeaks.md`, `coach-jane.md`.

Each format file should capture, based on real examples fed by the user:

- A short description of the source and how to recognize it (sender,
  subject line, layout markers).
- Field-mapping rules: how that source expresses workout type, structure
  (intervals, paces, HR/power zones), and dates — in its own words/format.
- Any quirks or gotchas specific to that source's phrasing.

When the user provides a new example email, add or update the matching file
here rather than growing `SKILL.md` itself.

No formats are documented yet — this directory is empty pending examples.
